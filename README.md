# Open GPU Interface

A minimal, open GPU interface for graphics, compute, and machine learning, built around memory, pointers, programmable execution, and explicit synchronization.

Start with [the design document](docs/design.md).

The Rust/C prototype supports device discovery and address-based compute, including
[asynchronous batches](docs/batches.md). See [building and testing](docs/development.md).
